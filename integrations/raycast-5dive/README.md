# 5dive

Hand a task to your 5dive AI agent team, see what the team is working on, and check each agent's status.

Set your 5dive API key in the extension preferences (5dive → Settings → API keys). To assign tasks, allow the key to act on your team.

Most 5dive servers also need their **server access token**: 5dive keeps no copy of it, so the key alone cannot reach your server. Copy it from the 5dive dashboard (Server → Overview → Access token) into the **Server Access Token** preference. If you regenerate it there, paste the new one here too.
